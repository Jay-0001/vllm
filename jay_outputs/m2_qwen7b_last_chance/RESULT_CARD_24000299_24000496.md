# Qwen7B Q/K RoPE: intermediate shapes and burst frequency

## Result

On A100, the one-launch Q/K kernel beat current Inductor at every tested
intermediate size through 128 scheduled tokens, tied approximately at 256,
and had previously lost at 512 and 2048. All six new cases completed, Q/K/V
matched Inductor exactly on each seeded input, and the generated Inductor
wrappers still showed two RoPE launches. Each percentage below is a paired
CUDA graph replay region comparison from one job, not model latency.

| Scheduled tokens | Inductor median (µs) | Combined median (µs) | Combined gain |
| ---: | ---: | ---: | ---: |
| 8 | 4.789 | 2.246 | 53.1% |
| 16 | 5.089 | 2.357 | 53.7% |
| 32 | 5.505 | 2.718 | 50.6% |
| 64 | 4.386 | 2.735 | 37.6% |
| 128 | 4.960 | 3.744 | 24.5% |
| 256 | 5.935 | 6.020 | −1.4% |

The low and high groups ran on different A100s. The nonmonotonic absolute
Inductor time between 32 and 64 must not be read as a shape scaling curve.
The paired within-shape differences are the relevant comparison. The earlier
512 and 2048 prefill cases lost by about 30% and 22%, respectively.

## Bursty synthetic workload

The separate 16-request/s run completed 128 requests with no failures. Its
server log records 570 iterations: 463 pure decode, 106 mixed, one prefill.
Among pure decode iterations, 50 scheduled 1–4 tokens, 21 scheduled 5–7, and
392 scheduled 8–29. Thus 84.7% of pure decode iterations occupy the newly
tested 8–32 range. Mixed iterations scheduled 139–994 total tokens and are
outside the known advantageous shape range. The client reported mean TPOT
16.51 ms and 9.19 seconds benchmark duration. This is a synthetic burst,
not a production request trace.

The transferred burst directory includes `server.log`, `serve.json`, and
`shape_summary.json`; `iterations.csv` and `shape_histogram.csv` referenced by
the script were not present in the local copy. The counts above were
independently reconstructed from `server.log` using the script's iteration
regex. The missing CSVs do not invalidate the saved log, but should be
transferred for the full record.

## Thesis decision

This defeats the concern that the region win exists only at 1–4 scheduled
tokens. It establishes a substantial shape-dependent **local** Inductor
opportunity over decode sizes that occurred frequently in this burst. It does
not establish downstream model or serving improvement. A rough scale check:
even a few microseconds per layer is small beside the 16.51 ms mean TPOT;
integrating a custom op may add its own dispatch, compilation, or memory cost.

The prepared model script currently selects the oracle only through four
tokens and uses a fixed four-sequence batch. It does not test the dominant
8–29-token burst regime and should not be treated as this sweep's model-level
gate. The next controlled test must select the oracle for pure decode shapes
through about 32 while retaining stock behavior for mixed/prefill shapes,
verify the actual generated dispatch, and replay the same request sequence
against stock in paired order. If full-model benefit is absent or below the
predeclared practical threshold, close M2 despite the local kernel win.
